One-time setup. This lets this page add pictures for you. You only do this once on this phone.

  1. Open this GitHub page.
  2. Name: image robot. Expiration: pick the longest.
  3. Under Repository access choose Only select repositories, then pick {{repo_name}}.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it, and paste it below.

The token is kept only on this phone. It can only add files to this one project. Never share it.
